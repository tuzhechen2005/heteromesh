## 技术路线认可与边界

- 连续层分片 + 单任务顺序执行适合首先证明容量，允许节点等待；不应把“所有GPU同时忙”作为早期成功标准。
- 分片输入明确时间条件、残差、位置与音频状态，方向正确；真实 H3 block 契约要从固定源码导出，不能以小型 Transformer 契约推断。
- MPS 与 iOS Core ML/ExecuTorch/MLX Swift均是候选适配途径，当前不能表决决定“完整 H3 支持”。iOS原生节点与模拟器构建可先实现，真机 GPU/内存和两台手机贡献保留 NOT RUN。
- 当前所有 CI/测试文档均正确区分软件门禁与真机验收。建议报告中保留每个 PRD 的 E0–E5 证据，不使用总体“全平台支持”标签概括。
